1️⃣ Mode Offline (Tanpa Google Sheets)

Bagaimana Cara Kerjanya?

Tanpa sinkronisasi Google Sheets, siswa tetap bisa mengerjakan ujian. Setiap siswa mengunduh bukti hasil berupa file yang berisi:

  • Nama & Kelas
  • Jawaban yang dipilih
  • Skor/Hasil
  • Waktu mengerjakan

Langkah-Langkah:

1
Siapkan Naskah Soal di Word

Buat soal dengan format yang benar. Kosongkan kolom URL Google Apps Script.

2
Generate CBT.html

Klik "Generate & Unduh CBT.html"

3
Bagikan ke Siswa

Kirim file CBT.html via WhatsApp, email, Google Classroom, atau hosting ke web.

4
Siswa Mengerjakan

Siswa buka file, isi nama/kelas, lalu kerjakan soal. Setelah selesai, klik "Selesai Ujian".

5
Siswa Unduh Bukti Hasil

File bukti hasil bisa diprint atau dikirim ke guru via WhatsApp/email.

Tips: Mode offline cocok untuk ujian di ruang komputerLAB yang tidak terhubung internet, atau jika belum punya akun Google.

2️⃣ Mode Online (Dengan Google Sheets)

Keuntungan Menggunakan Google Sheets:

  • ✅ Hasil ujian tersimpan otomatis ke spreadsheet
  • ✅ Guru bisa memantau real-time siapa saja yang sudah mengerjakan
  • ✅ Tidak perlu kumpulkan bukti hasil dari setiap siswa
  • ✅ Data terpusat dan mudah diolah (Excel/Google Sheets)
  • ✅ Bisa langsung hitung statistik, grafik, ranking

Yang Dibutuhkan:

  • Akun Google (Gmail)
  • Aplikasi Google Sheets (gratis)
  • Koneksi internet saat ujian (untuk siswa)

Langkah 1: Buat Google Sheets Baru

1
Buka Google Sheets

Buka sheets.google.com dan login dengan akun Google Anda.

2
Buat Spreadsheet Baru

Klik "+ Blank" atau "Baru → Google Sheets → Blank spreadsheet"

3
Beri Nama

Ubah nama menjadi, contoh: "Hasil Ujian IPA Kelas 7A"

4
Siapkan Header Kolom

Di baris pertama, isi header seperti ini:

Timestamp | Nama | Kelas | Skor | Jawaban | Durasi (menit)

Ini adalah header WAJIB. Jangan diubah urutannya.

Perhatikan: Kolom harus persis berurutan: Timestamp, Nama, Kelas, Skor, Jawaban, Durasi. Urutan ini WAJIB sesuai karena CBT akan mengirim data berdasarkan urutan kolom.

3️⃣ Buat Google Apps Script

Apa itu Google Apps Script?

Google Apps Script adalah kode yang menghubungkan CBT dengan Google Sheets Anda. Kode ini berjalan di server Google, sehingga tidak perlu hosting sendiri.

Langkah-Langkah:

1
Buka Apps Script

Di spreadsheet Anda, klik menu: Extensions → Apps Script

2
Hapus Kode Default

Di editor kode yang muncul, hapus semua kode yang ada (biasanya function myFunction).

3
Salin Kode Berikut:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  try {
    var data = JSON.parse(e.postData.contents);

    var timestamp = new Date();
    var nama = data.nama || '';
    var kelas = data.kelas || '';
    var skor = data.skor || 0;
    var jawaban = JSON.stringify(data.jawaban || {});
    var durasi = data.durasi || 0;

    sheet.appendRow([timestamp, nama, kelas, skor, jawaban, durasi]);

    return ContentService
      .createTextOutput(JSON.stringify({status: 'success'}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({status: 'error', message: error.message}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
4
Simpan Kode

Klik tombol 💾 Save (disk icon) atau Ctrl+S.

Jangan ubah nama fungsinya! Nama function harus tetap doPost(e) karena itu yang dipanggil oleh CBT.

4️⃣ Deploy sebagai Web App

1
Buka Deploy Options

Klik Deploy → New deployment

2
Pengaturan Deployment

Klik ikon ⚙️ Select type → Web app

3
Konfigurasi Web App

Isi pengaturan seperti ini:

DescriptionSi Gatot CBT Results
Execute asMe (alamat email Anda)
Who has accessAnyone (atau "Anyone with Google account")
4
Deploy

Klik Deploy dan tunggu proses selesai.

5
Copy URL

Setelah berhasil, akan muncul Web app URL. Copy URL tersebut.

Contoh URL: https://script.google.com/macros/s/AKfycbw.../exec

Penting: Setiap kali Anda mengubah kode Apps Script, Anda harus Deploy ulang (Deploy → Manage deployments → Edit → Deploy) untuk memperbarui URL.

5️⃣ Uji Coba

1
Buka URL di Browser

Buka URL Web app yang sudah dicopy di browser baru (incognito lebih baik).

2
Test Kirim Data

Jika muncul error atau halaman kosong dengan {"status": "success"}, berarti berhasil!

Jika muncul halaman login Google, berarti pengaturan "Who has access" kurang. Ubah ke Anyone.

3
Cek Google Sheets

Buka spreadsheet Anda. Seharusnya ada baris baru dengan timestamp. Jika ada, berarti koneksi berhasil!

Tips: Test dengan data dummy dulu sebelum ujian sebenarnya.

7️⃣ Tips & Troubleshooting

Tips Penting:

TipsPenjelasan
Gunakan spreadsheet TERPISAH Gunakan 1 spreadsheet per kelas per ujian agar data tidak campur aduk.
Test sebelum ujian Lakukan test upload dan kerjakan dummy 1 soal sebelum ujian正式开始.
Backup rutin Download hasil sebagai Excel secara berkala sebagai backup.
Pastikan siswa online Sinkronisasi butuh koneksi internet. Siswa bisa kerjakan offline tapi hasil sync saat koneksi tersedia.

Troubleshooting:

MasalahSolusi
"URL tidak valid" Pastikan URL Apps Script benar dan sudah di-deploy dengan "Anyone" access.
Hasil tidak muncul di Sheets
  1. Cek apakah URL Apps Script masih aktif (buka di browser)
  2. Pastikan urutan kolom header sudah benar
  3. Cek apakah ada error di Apps Script (Extensions → Apps Script → Executions)
Error CORS Hapus https:// dari awal URL Apps Script (cukup yang dari /macros/...)
Data tidak sinkron Pastikan siswa klik "Selesai Ujian" di akhir. Data dikirim saat siswa submit.
Spreadsheet penuh/berat Hapus baris kosong atau backup ke file terpisah, lalu kosongkan spreadsheet.
